## 2024-11-02 - Avoid compiling Regex in Hot Paths
**Learning:** `FavoritesManager.kt` compiles multiple regular expressions on-the-fly (`Regex("[\\s\\-./]+")` and `Regex("\\b${Regex.escape(query)}\\b")`) inside `matchesFavorite` which is called repeatedly when filtering lists of games (e.g. `games.filter { ... }`). The `matchesFavorite` function can easily be executed hundreds of times in a hot loop (like when verifying widget contents or rebuilding scoreboards), meaning this regex recompilation negatively impacts UI responsiveness.
**Action:** Always precompile constant Regex expressions via companion objects and rewrite dynamic regular expression boundary checks using manual string matching (e.g., using `indexOf` and checking neighboring characters) to avoid recompilation overhead inside loops.
